# 🔢 Even & Odd Number Analyzer

A simple and beginner-friendly Python script that analyzes numbers within a user-defined range, separating them into even and odd lists and displaying their total counts.

## 🚀 Features
- Takes user input for a starting and ending range.
- Uses `for` loop and modulus operator `%` to filter numbers.
- Stores even and odd numbers in separate lists.
- Displays the list of numbers along with the total count (length).

## 💻 How to Run
1. Make sure you have Python installed.
2. Run the file using your terminal or IDE:
   ```bash
   python "Even & Odd Number Analyzer.py"
